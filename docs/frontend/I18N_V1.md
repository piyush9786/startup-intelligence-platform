# Multi-Language Support (i18n)

Phase: Frontend Feature
Status: Implemented

## Overview

The platform supports multiple languages natively without relying on heavy third-party internationalization libraries (like `react-i18next` or `vue-i18n`). This keeps the client bundle lightweight and execution deterministic, aligning with the platform's focus on performance and minimal dependencies.

Currently supported languages:
- **English (`en`)** - Default, primary source of truth.
- **Hindi (`hi`)** - हिन्दी
- **Marathi (`mr`)** - मराठी

## Architecture

The internationalization (i18n) system is implemented entirely via React Context and a custom translation hook.

### Core Components

1. **`LanguageProvider` (`src/i18n/index.jsx`)**: A React Context provider that wraps the application root. It manages the active language state and persists it to `localStorage` under the `startup_os_lang` key.
2. **Translation Dictionaries**: 
   - `src/i18n/en.js`
   - `src/i18n/hi.js`
   - `src/i18n/mr.js`
3. **`useT` and `useLanguage` Hooks**: 
   - `useLanguage()` provides the current language code and the `setLanguage` mutator.
   - `useT()` provides the `t(key, vars)` function to retrieve and interpolate translated strings.
4. **`LanguageSwitcher.jsx`**: A floating globe button placed in the bottom-right corner. It uses glassmorphism and is accessible across both public unauthenticated entry points and the authenticated founder/reviewer workspaces.

### The `t()` Function

The `t(key, vars)` function uses a strict fallback mechanism:
1. It attempts to find the translation in the currently selected language dictionary.
2. If the key is missing, it falls back to the English dictionary (`en.js`).
3. If the key is missing in English, it returns the string key itself (e.g., `brand.name`) to prevent crashes while clearly indicating missing translations during development.

It supports variable interpolation using a `{var_name}` syntax:
```javascript
// Dictionary
{
  "landing.schemes_count": "{count}+ verified government schemes"
}

// Usage
t("landing.schemes_count", { count: 42 })
// Output: "42+ verified government schemes"
```

## Adding Translations

When developing new features:
1. **Never hardcode UI text.** Use `const { t } = useT();` and replace text with `t("feature.key")`.
2. Add the key and its English value to `src/i18n/en.js` first. This is the source of truth.
3. Provide the corresponding keys and localized values in `hi.js` and `mr.js`.

## Accessibility (a11y)

The `LanguageProvider` automatically updates the `<html lang="xx">` attribute whenever the language changes, ensuring screen readers, browsers, and font rendering engines apply the correct locale rules.

The `LanguageSwitcher` itself supports keyboard navigation (Escape to close, proper focus states) and clear ARIA labels indicating the current and available languages.
