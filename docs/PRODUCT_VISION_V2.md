# Product Vision v2 — AI Startup Operating System

## Vision

Build an AI startup operating system that helps founders validate, fund, build,
and manage a startup using verified government data, structured financial
intelligence, stateful AI guidance, and transparent source provenance.

The founder journey is:

```text
Discover an opportunity
→ define a problem
→ understand customers
→ validate demand
→ create the startup
→ build an MVP
→ plan sales
→ identify schemes and funding
→ allocate capital
→ execute milestones
→ track progress
→ ask contextual questions anywhere
Product principles
AI assists; authoritative systems decide

Language models may:

extract information from documents;
explain verified records;
suggest startup experiments;
draft customer and sales plans;
narrate financial scenarios;
summarize founder context.

Language models must not independently decide:

verified eligibility;
official application deadlines;
reviewer verification;
legal or compliance status;
authoritative prerequisite ordering;
financial calculations;
source authenticity.
Every consequential output is traceable

Important outputs must preserve:

founder inputs;
source documents;
extracted evidence;
deterministic calculation inputs;
engine and prompt versions;
model identity;
confidence;
founder confirmation;
reviewer verification where required.
